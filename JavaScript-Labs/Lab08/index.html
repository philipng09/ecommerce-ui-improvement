Lab 08

JavaScript 1: Language Foundations

Cú pháp, biến, kiểu dữ liệu, hàm, String, Date, Array, Object và Browser Console. Gồm 11 Exercise, bấm vào từng mục để xem kết quả chạy thực tế.

  1. 8.1 Enabling/Disabling JavaScriptBật, tắt JavaScript trên trình duyệt và kiểm tra thông báo hiển thị. exercise8-1.html
  2. 8.2 Embedded JavaScriptNhúng mã JavaScript trực tiếp trong thẻ <script>, hiển thị hộp thoại alert(). exercise8-2.html
  3. 8.3 External JavaScriptTách mã ra file hello.js, dùng document.write() và biến đếm count. exercise8-3.html
  4. 8.4 Using noscriptThêm thông báo <noscript> cho người dùng tắt JavaScript. exercise8-4.html
  5. 8.5 Using the Browser ConsoleChuyển file vào thư mục js/, đọc lỗi và dùng console.log(), warn(), error(). exercise8-5.html
  6. 8.6 Using Built-in JavaScript ObjectsSo sánh String object và literal (== và ===), dùng Date và Math. lab08-walkthrough06.html
  7. 8.7 ArraysDùng push(), unshift(), vòng lặp và điều kiện để tạo bảng lịch 30 ngày. lab08-walkthrough07.html
  8. 8.8 JavaScript FunctionsHàm có tham số, giá trị trả về, phạm vi biến cục bộ và toàn cục. lab08-walkthrough08.html
  9. 8.9 Functions as ObjectsHàm lồng nhau, hàm ẩn danh và truyền hàm làm tham số để tính thuế. lab08-walkthrough09.html
  10. 8.10 Creating JavaScript ObjectsTạo đối tượng đơn hàng bằng object literal và hàm khởi tạo. lab08-walkthrough10.html
  11. 8.11 Arrays of ObjectsDuyệt mảng đối tượng quốc gia bằng for và for..in, hiển thị cờ. lab08-walkthrough11.html

Mẹo: nhấn F12 và mở tab Console để xem thông báo của các Exercise có dùng console.log().
