CÁCH UP GITHUB:
1. Clone repo https://github.com/KienNguyen1504/ecommerce-ui-improvement.git
2. Copy nguyên thư mục Buoi5 vào thư mục gốc repo (cùng cấp với index.html cũ).
3. git add Buoi5
4. git commit -m "Add Buoi 5 Dino and responsive exercise"
5. git push origin main
6. GitHub > repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
7. Mở: https://kiennguyen1504.github.io/ecommerce-ui-improvement/Buoi5/

LƯU Ý: Không thay index.html cũ ở gốc repo. Cần tự chụp màn hình game Dino đang chạy
với Console cho hai lệnh thay đổi tốc độ và độ nhảy, sau đó chèn vào báo cáo Word.
